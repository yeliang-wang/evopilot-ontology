# Ontology specifications

[Corrected v1](v1/README.md) is the current basis for public/private projects and forward/reverse workflows. RDF/Turtle, RDFS/OWL and SHACL are W3C standards; pySHACL is the upstream implementation. EvoPilot defines package structure, source/coverage bindings and lifecycle. These are different layers.

A v1 label alone cannot identify normative content. Every new package binds installed standard, lock, producer and contract digests. Old JSON definitions remain in historical commits/releases; current tasks re-extract native assets and cannot inherit old PASS decisions.
