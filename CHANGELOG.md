# Changelog

## 0.1.1 Preview

- Deliver owned implementation as strict TypeScript 5.9.3 compiled to JavaScript and declarations. Public exports and CLI use `dist`; remove the 17 duplicate top-level `.mjs` implementations after confirming their `.ts` counterparts.
- Retain historical compatibility JavaScript behind a typed boundary, with original schema IDs, APIs, frozen native v1 assets, provenance and vendor contract unchanged.
- Refresh navigation, capabilities, native/compatibility distinctions, provider requirements, source quickstart and release-tarball installation instructions.
- Include contribution, security and changelog documents in the package and synchronize the package metadata check.

This is a source delivery and documentation repair, with no new product features. See the [v0.1.1 Preview release](https://github.com/yeliang-wang/evopilot-ontology/releases/tag/v0.1.1).

## 0.1.0 Preview

The [historical published release](https://github.com/yeliang-wang/evopilot-ontology/releases/tag/v0.1.0) introduced the native v1 model, instance validation and immutable delivery contract, the scoped durable service and CLI, and retained compatibility queries, producers, Catalog and classification. Historical provenance and contributor attribution remain intact.
